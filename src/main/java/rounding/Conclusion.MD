# Методы округления класса Math в Java

## 1. `Math.floor(double a)` - Округление вниз

Возвращаемый тип: `double`

Правило округления:
- Округляет вниз к отрицательной бесконечности
- Для положительных чисел: отбрасывает дробную часть
- Для отрицательных чисел: округляет в сторону большего по модулю числа

**Примеры:**

`Math.floor(12.5)` → `12.0`

`Math.floor(-4.5)` → `-5.0`

`Math.floor(99.99)` → `99.0`

---

## 2. `Math.ceil(double a)` - Округление вверх

Возвращаемый тип: `double`

Правило округления:
- Округляет вверх к положительной бесконечности
- Для положительных чисел: округляет к следующему целому, если есть дробная часть
- Для отрицательных чисел: отбрасывает дробную часть

**Примеры:**

`Math.ceil(12.5)` → `13.0`

`Math.ceil(-4.5)` → `-4.0`

`Math.ceil(10000.1)` → `10001.0`

---

## 3. `Math.rint(double a)` - Банковское округление

Возвращаемый тип: `double`

Правило округления:
- Округляет к ближайшему целому
- При x.5: округляет к ближайшему чётному числу

**Примеры:**
- `Math.rint(12.5)` → `12.0` (чётное)
- `Math.rint(-4.5)` → `-4.0` (чётное)
- `Math.rint(99.99)` → `100.0`

---

## 4. `Math.round(double a)` - Стандартное округление

Возвращаемый тип: `long`

Правило округления:
- Округляет к ближайшему целому
- При x.5: округляет вверх (к положительной бесконечности)

**Примеры:**
- `Math.round(12.5)` → `13`
- `Math.round(-4.5)` → `-4`
- `Math.round(99.99)` → `100`
